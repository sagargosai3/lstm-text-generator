# LSTM Text Generation (PyTorch)

## Overview
This project implements a text generator using an LSTM model in PyTorch.  
The model is trained on Shakespeare text and generates new sequences based on seed input.

---

## Dataset
Shakespeare Dataset (Project Gutenberg):  
https://www.gutenberg.org/files/100/100-0.txt

---

## Features
- Text preprocessing (lowercase, punctuation removal)
- Tokenization and sequence generation
- LSTM-based neural network
- Text generation using seed input
